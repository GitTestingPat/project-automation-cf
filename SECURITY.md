# Política de Seguridad

## Versiones con soporte

Este es un proyecto personal. Solo se da soporte a la rama `main`.

## Reportar una vulnerabilidad

Por favor, no abras un issue público.

Reporta de forma privada desde la pestaña **Security** → **Report a vulnerability**
de este repositorio.

Este proyecto lo mantiene una sola persona, así que no puedo garantizar plazos
de respuesta, pero intentaré revisar los reportes en cuanto pueda.
